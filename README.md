# Стіч і шишки

Гра для 5-річної дитини: плюшевий Стіч бігає лісовою стежкою і збирає шишки, що падають із сосен.

- Грати: https://newhope77.github.io/stich-shyshky/
- iPad: Safari → «Поділитися» → «На початковий екран» — гра відкривається на весь екран, як застосунок.
- `#demo` у кінці адреси — Стіч сам бігає за шишками (показ / перевірка).

## Збірка
```
python3 src/build.py        # game.html + спрайти → docs/index.html
```
Спрайти: `src/cutout.py` (rembg, вирізає з фото) → `src/sprites.py` (WebP).
